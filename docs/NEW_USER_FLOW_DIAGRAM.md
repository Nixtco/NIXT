## التدفق المختصر | Simplified Flow

```
المستخدم يسجل → يدخل Dashboard → لا توجد محادثات
    ↓
جلب قائمة الإداريين
    ↓
إنشاء محادثة general مع أول admin
    ↓
الاتصال بـ WebSocket + الانضمام للمحادثة
    ↓
عرض رسالة ترحيبية
    ↓
المستخدم يكتب رسالة → إرسال عبر WebSocket
    ↓
حفظ في قاعدة البيانات → Broadcast للطرفين
    ↓
عرض الرسالة في الواجهة
    ↓
✅ النجاح!
```

## الحالات الاستثنائية | Exception Cases

### ❌ Case 1: No Admins Available

```
لا يوجد admins
    ↓
❌ عرض رسالة خطأ
    ↓
"لا يوجد مسؤولين متاحين حالياً. يرجى المحاولة لاحقاً."
```

### ❌ Case 2: WebSocket Connection Failed

```
فشل اتصال WebSocket
    ↓
🔄 إعادة المحاولة (3 مرات)
    ↓
إذا فشل → استخدام REST API كـ fallback
```

### ❌ Case 3: Database Error

```
خطأ في قاعدة البيانات
    ↓
❌ عرض رسالة خطأ
    ↓
"حدث خطأ في حفظ الرسالة. يرجى المحاولة مرة أخرى."
```

## مقارنة قبل وبعد الحل | Before vs After

### ❌ BEFORE (المشكلة)

```
المستخدم الجديد → لا توجد محادثات
    ↓
activeConversationId = null
    ↓
WebSocket يحاول الاتصال بدون conversationId
    ↓
❌ خطأ 1006 - WebSocket closed
    ↓
🔄 إعادة محاولة (تفشل)
    ↓
❌ المستخدم لا يستطيع إرسال رسائل
```

### ✅ AFTER (الحل)

```
المستخدم الجديد → لا توجد محادثات
    ↓
📝 إنشاء محادثة general تلقائياً
    ↓
activeConversationId = conversation.id
    ↓
WebSocket يتصل بنجاح
    ↓
✅ عرض رسالة ترحيبية
    ↓
✅ المستخدم يستطيع إرسال رسائل
```
